# FastApi-site
## Описание
Creating a website using the FaseApi framework using Celery, Flower, Postgresql, SQLAlchemy. Also writing DockerFile and docker-compose.

Этот проект представляет собой веб-приложение, разработанное с использованием FastAPI. Оно демонстрирует основные возможности фреймворка, включая создание RESTful API, работу с базами данных и аутентификацию пользователей. Также реализовано продключение к Celery и Flower, а также к хранилищу Redis. Приложение подходит как для учебных целей, так и для разработки более сложных решений.

## Установка

### Предварительные требования

- Python 3.7 или выше
- pip

### Клонирование репозитория

Сначала клонируйте репозиторий на свой локальный компьютер:

```bash
git clone https://github.com/PoroSenok-sys/FastApi-site.git
cd FastApi-site
```
### Установка зависимостей
Установите необходимые зависимости:

```bash
pip install -r requirements.txt
```
## Использование
Настройте базу данных. Вы можете использовать SQLite или другую поддерживаемую базу данных. Конфигурация базы данных находится в config.py.

Запустите приложение:

```bash
uvicorn main:app --reload
```
Перейдите в браузер по адресу http://127.0.0.1:8000, чтобы увидеть приложение в действии.

Для доступа к автоматической документации API перейдите по адресу http://127.0.0.1:8000/docs.

## Функции:
- Создание, чтение, обновление и удаление данных через RESTful API.
- Поддержка аутентификации пользователей с использованием JWT.
- Интерактивная документация API с помощью Swagger.

## Тестирование
Вы можете запускать тесты, чтобы убедиться, что все функции работают правильно. Для этого выполните:

```bash
pytest
```
